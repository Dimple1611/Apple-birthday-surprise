PUBLISH FREE:
1. Sign in or create a free account at https://github.com/
2. Create a public repository, e.g. apple-birthday.
3. Upload index.html, README.txt, and the photos/ and music/ folders.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /root,
   then Save.
6. After GitHub finishes publishing, it will show your public website URL.

Keep all files and folders in the same structure when uploading.
