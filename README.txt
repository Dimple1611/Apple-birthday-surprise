APPLE'S BIRTHDAY WEBSITE — PERSONALIZED EDITION

Your five selected photos have been cropped neatly to a consistent portrait shape
and added to the gallery:
  photos/photo1.jpg through photos/photo5.jpg

The birthday letter is your supplied message, placed in the interactive reveal.
The countdown automatically counts down to the next November 11.

MUSIC:
The page displays “I Wanna Be Yours” by Arctic Monkeys, but the audio file itself
is not included. Add an audio file you are legally allowed to use as:
  music.mp3
Then the play/pause button will play it. The browser may require a tap to start.

PUBLISH FREE:
1. Sign in or create a free account at https://github.com/
2. Create a public repository, e.g. apple-birthday.
3. Upload index.html, README.txt, and the photos/ and music/ folders.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /root,
   then Save.
6. After GitHub finishes publishing, it will show your public website URL.

Keep all files and folders in the same structure when uploading.
